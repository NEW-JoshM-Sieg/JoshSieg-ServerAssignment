# brew-guides

Markdown brew guides for the **Riverstone Coffee Roasters** website. The storefront (`storefront-web`, built by Marcus Lee) pulls these files in at build time and shows them on each product page and under "How to brew".

## Guides

- [Pour-over](guides/pour-over.md)
- [French press](guides/french-press.md)
- [Espresso](guides/espresso.md)

## How to use / preview

These are plain Markdown, so GitHub renders them directly. To preview them the way the site does, run the storefront locally and open `/brew`.

## Writing rules

- Follow the Brand Voice Guide in Notion: warm, plain, no jargon without an explanation.
- Give doses in grams and ratios, plus a cups/tablespoons fallback.
- Every guide ends with a "Try it with" line recommending a Riverstone coffee (this season: the Holiday Blend).
