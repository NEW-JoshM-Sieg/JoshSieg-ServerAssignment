# barista-training

Training material for new baristas at **Riverstone Coffee Roasters**: a first-two-weeks checklist and a short quiz. It matches the Barista Training Plan page in Notion.

## Contents

- [`checklist.md`](checklist.md): what a new barista should be signed off on, week by week.
- [`quiz.json`](quiz.json): multiple-choice quiz, also used for the holiday market staff refresher.
- [`quiz.py`](quiz.py): runs the quiz in a terminal.

## How to run the quiz

```bash
python quiz.py
```

No dependencies beyond Python 3.9+.

## Who is involved

- **Dana Whitfield** (operations manager): owns the training program and signs off checklists.
- **Owner**: teaches the roastery and origin sessions.
- Staff working the **Beacon Holiday Market** booth (Dec 12-13) take the quiz as a refresher on pour-over and the Holiday Blend.
