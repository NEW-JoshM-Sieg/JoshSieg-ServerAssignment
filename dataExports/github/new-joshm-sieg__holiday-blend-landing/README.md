# holiday-blend-landing

A one-page landing site for the limited **Holiday Blend** from Riverstone Coffee Roasters: 60% Ethiopia Yirgacheffe + 40% Colombia Huila, roast profile B (light-medium).

The page goes live with the storefront on **November 10** and links to the Holiday Blend product page. The QR code on the Beacon Holiday Market flyers (Dec 12-13) points here.

## How to run

It's a static page with no build step:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
